# ExpiryBot
ExpiryBot takes a look at your data, suggests some retention groups (e.g., "tax documents and accessories, retain for 3-7 years"), and discusses those suggestions with you until you decide on a retention taxonomy. It then flags documents that have exceeded the retention period you decided on, so that you can delete them. It never deletes the documents itself, but it can move the documents to a /deprecate/ subfolder if you ask it to, which is handy if you want to hold on to emotional support data but also want to exclude that data from a RAG knowledge base or agentic context.
