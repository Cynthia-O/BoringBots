# FormBot
This bot will have three jobs:
- Extract text from and comprehend the purpose of fields within any uploaded PDF or Word format form. Bot should in its initial version only need to manage one form at a time, but the form may be several pages long and contain a mixture of text and images.
- Research unclear fields as needed from the appropriate internet links and cache findings and direct link references supporting those findings for the duration of the user session.
- Work with the user to fill out the form field by field. The bot will converse with the user and can provide text for copy-pasting, but will not have the power to make any direct changes to the form.

Initial scope:
- PDF or Word format only. Single form at a time only. Reference open internet pages (pages not requiring logon).

Future scope:
- Additionally reference user's supporting materials in the form of Google Docs and Google Sheets, and previously filled forms.
